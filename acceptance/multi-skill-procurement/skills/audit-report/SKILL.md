---
name: audit-report
description: Present a purchase decision with traceable budget and calculation evidence.
---

Use after budget-query and purchase-review. Obtain their actual execution results.
Explain the cost centre, requested amount, available budget, decision and exact
shortfall, all monetary amounts in yuan with two decimal places. Include the source
data file and the actual calculation tool/script used. Clearly state that this is
an assessment: no approval has been committed and no money was reserved or debited.
If data is unavailable, report the missing data instead of guessing.
