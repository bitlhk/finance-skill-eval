# 应收账款核对

1. 调用 `open_ledger(customer_id)` 获取本次核对句柄和记录数。业务系统返回的大明细留在工具进程，不能在模型上下文复制它。
2. 将工具返回的精确 `ledger_ref` 传给 `summarize_ledger(ledger_ref)`，返回币种、笔数、未收总额。不得编造、截断或更换句柄。
3. 完成后调用 `close_ledger(ledger_ref)` 释放明细，再根据实际结果答复。空账本输出零笔零金额；客户不存在明确报告，不伪造句柄。

这些业务工具的实现都在 tools/ledger.py；原先通过 tools/register.py 注册给 Agent。上下文就是这个业务模块自己的 `_ledgers`，不依赖模型记忆、跨任务持久化或框架的隐式全局状态。迁移时应保留工具逻辑，在同一 MCP 服务生命周期内共享句柄；不能把它转给 Builder 重写。一个测试任务结束即销毁对应 MCP 服务，句柄不得跨任务复用。

工具执行失败时说明具体限制，不根据用户提示猜测余额。工具只读业务明细，不催款、记账或改变业务系统。业务日期由服务数据给出，不要求用户额外配置。
