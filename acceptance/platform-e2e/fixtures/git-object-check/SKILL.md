---
name: git-object-check
description: 使用企业执行环境已有的 Git 命令检查文件对象标识，不修改仓库或业务数据。
---

用户提供工作区内文件时，使用已安装的 Git CLI 执行 `git hash-object --no-filters -- <文件路径>`，报告命令输出的对象标识。
不要添加 `-w`，不要运行 checkout、reset、clean 或其他写入命令。路径必须作为一个独立参数传递，不能拼接为可执行 shell 代码。
文件不存在或命令失败时如实报告错误，不编造标识。不要用模型估算或自行实现另一套哈希代替 Git 的对象语义。

运行条件：受管环境已安装 Git 2.x，提供非交互命令执行和超时控制。通过 `git --version` 核实版本；此能力无账号、网络或服务部署需求。成功时 stdout 为对象标识，错误通过 stderr 和非零退出码返回。读操作无重试副作用，也无需 --yes 或 --dry-run。
