# 页面与应用服务的数据边界

`responses.d.ts` 是页面使用的公开响应类型，不导入后端实现。浏览器代码只依赖这里的数据合同，不依赖 `src/` 中的服务、Agent 或存储模块。

迁移时已经提取为独立数据声明，原 TypeScript 后端和类型提取器已撤销。请求以 `schemas/` 下公开 JSON Schema 为准；修改 API 时同步响应声明，并通过原生 HTTP 与页面回归检查字段兼容。

`evaluation-plan.js` 供页面的评测方案编辑器检查输入格式；不包含评分或脚本执行逻辑。Python 后端独立使用公开 JSON Schema 及评测业务规则校验。其声明文件使用 TypeScript 严格模式检查。

报告有效性、重复执行统计、人工意见的当前结论由后端计算，页面展示 API 返回值。表单草稿比较、输入提示和显示文案保留在 `web/`。后端必须独立检查所有提交，不能信任浏览器提示。
