## 工程检查

- TypeScript 类型检查、Core/Web 构建和既有回放回归。
- 17 个测试文件、36 项测试通过，包含 SSE 分块、缺少结束事件、基线污染、MCP 握手回收、候选文件约束和留出隔离。
- Python 模拟 Provider 对变更金额、期限和流动性要求返回待核验，不静默复用旧约束。
- 1440px 桌面与 390px 手机浏览器检查 Markdown、评分图和候选面板，无页面错误或横向溢出；截图保留在本机 `reports/`。
- Worker 每侧独立进程和 MCP 会话，结束及取消执行回收；Codex 超时和取消按进程组清理。
- 模型密钥与 MCP 认证只保存在忽略提交的本机配置；服务绑定回环地址，个人 Codex 登录不作为公网共享账户。

## 仍需验证的范围

财富是本轮完成在线接线的首个 Skill。其他岗位需要相应 Skill 包、工具及业务快照，不能仅凭精选列表声称已在线支持。默认 Worker 仅挂载文档和显式允许的只读 MCP，不运行上传脚本或实际交易。未来接银行测试环境时需替换 Provider、核对身份及数据用途，并重新跑业务案例。

目前是小样本、单次生成候选机制，不是自动优化保证。推荐 SOP 的实际使用、更多留出案例、重复运行稳定性和人工专业复核，仍是后续证明质量提升需要补充的证据。
