# 直连上游部署

目标是把灵感平台原始上游地址改为 `https://111.119.236.165:15671`。域名仍由 116.204.37.89 的平台网关承载，用户入口不变。

```text
finance-eval.demo.linggan.top
  -> 116.204.37.89 Nginx：SSO、身份与服务令牌
  -> HTTPS 111.119.236.165:15671：来源 IP 限制
  -> 127.0.0.1:56371：原评测服务
```

## 网络和服务

- 新加坡云安全组新增入站 TCP 15671，来源仅 `116.204.37.89/32`，不要放行全部公网。
- 独立用户服务 `finance-eval-origin` 使用仓库 `deploy/finance-eval-origin.nginx.conf`。不启动或修改本机系统级 Nginx，不暴露 Runtime、MCP 或完整开发实例。
- Origin Nginx 也按真实 TCP 来源限制访问，不信任客户端伪造的 X-Forwarded-For。
- 原服务仍监听 loopback 56371，其 Bearer 校验及可信身份要求不变。Origin 不生成、替换或记录服务令牌。

## TLS

`.public-demo/origin/origin.key` 为新加坡本机私钥；`origin.crt` 为仅供网关验证的专用证书，包含 IP SAN。私钥不传往网关，不提交仓库。

网关仅信任此证书，并在 Finance Eval 专用 vhost 中设置：

```nginx
proxy_ssl_verify on;
proxy_ssl_trusted_certificate /etc/nginx/ssl/finance-eval-origin.crt;
proxy_ssl_name 111.119.236.165;
```

不要以 `proxy_ssl_verify off` 或跨公网明文 HTTP 替代现有 SSH 隧道的传输保护。证书有效期一年，应在到期前更新证书并同步网关信任文件。

## 切换顺序

1. 配好新加坡入口和来源限制，用户放行云安全组。
2. 从网关主机用指定证书验证 TLS，确认 `/api/health` 返回 200；无凭据访问 `/api/catalog` 应返回 401。
3. 配置网关证书校验，将平台原始地址改为 HTTPS IP URL，执行单条路由发布。
4. 检查公开域名健康、登录跳转、身份传递和实时流；通过后再停用旧隧道。

未完成直连验证前，后台继续使用 `http://127.0.0.1:15671` 的旧隧道入口，不提前切断访问。回退时恢复该地址并单条发布，保留隧道服务及原网关配置备份。

已切换并单条发布 `https://111.119.236.165:15671`。网关专用 vhost 开启 Origin 证书验证，旧 `finance-eval-public-tunnel` 已停用并取消自启，配置保留以供回退。
