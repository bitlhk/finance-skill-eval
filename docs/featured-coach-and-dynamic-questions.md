# 精选金牌教练与动态出题

## 本次范围

- 精选列表增加赵印伟的 `goldencoach-stage-evaluation@2.2.1`，显示名称为「金牌教练」。不修改原 Skill，不改变 EA 发布版本。
- 来源为已核对上海发布版本的 EA reference role pack。导入保留主文档和参考文件；Finance Skill Eval 重新计算完整文件包指纹，因此不把它冒充 EA 的目录/归档指纹。
- 三道固定回归题覆盖阶段点评、完整复盘和输入不足。它们是模拟训练题，不是独立人类专家签署的 Ground Truth。
- 精选在线评测默认 AI 动态出题；固定回归题仍可显式选择。上传资产已准备的题集、历史报告与冻结回放保持原语义。

## 每轮链路

```text
开始测试
  -> 进入原有任务队列
  -> 读取所选 Skill 版本及 references/templates
  -> Analyzer 结合任务范围与可用工具生成最多三题
  -> 校验结构、工具范围、题号和参考题重复
  -> 持久化本轮题目、量表、来源文件、模型与指纹
  -> 左右候选使用同一批题，在线执行
  -> 匿名 Judge -> 图形报告与运行记录
```

纯文本任务只给出题模型任务范围，不提供完整旧题，避免复制对话。六个工具型精选 Pack 在 `metadata.generationContext` 中保存机器可读的模拟对象与任务输入，出题时使用这些对象和任务范围，不注入完整旧题及标准答案。其他未提供该字段的 Pack 可使用原有任务种子，但同样拒绝复制题面。允许变换任务问题及交付要求，不允许改写后台事实。

出题不读取留出集、封存映射或评分标签；不向答题模型透露预期答案。Skill 的专属格式不自动成为判优标准。生成结果仍属于 AI 设计的探索性测试，不等于代表性完整的银行验收试卷。

## 冻结与失败语义

- 新的「开始测试」重新请求 Analyzer；不从旧题集缓存直接返回。
- 同一次 A/B 两边共享冻结题集，不能各自生成问题。
- 失败后「单次重试」沿用已生成题集；出题阶段尚未成功才重新出题。
- 本地优化复测使用原动态题加独立冻结留出题，不重新出一套更容易的题。公开演示仍不开放资产优化。
- 出题最长 120 秒，最多一次结构修复；取消向模型请求传递 AbortSignal。失败明确显示，不自动回退固定题。
- 精确复制旧题（包括只改空白或标点）会被拒绝。该检查不声称能检测所有语义近似，更不保证每轮题目都天然有足够区分度。

## 模型与工具

当前 Analyzer 使用已验证火山连接的 GLM-5.2，服务端设置有限输出和关闭该模型的深度思考选项。用户确认后，执行默认已切回 GLM-5.2，Judge 仍为 GPT-6-astra。三种角色独立配置。GLM-5.3 Flash 保留为手动可选项。

可用 `FINANCE_EVAL_ANALYZER_REQUEST_DEFAULTS` 配置出题连接特有参数，例如 `{"thinking":{"type":"disabled"},"temperature":0.7,"max_tokens":6000}`。参数与凭据由服务端注入，不向浏览器暴露凭据，也不更改所有模型的通用默认值。

金牌教练没有业务 MCP 需求，所需参考阅读由 Runtime 的 `read_file` 完成；不能把环境绑定了一个 MCP 解释为这次真的调用了一个 MCP。
