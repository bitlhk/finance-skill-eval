# 精选岗位在线演示发布记录

> 部署链路更新：2026-09-07 已切换为网关直连新加坡 HTTPS 上游，旧反向隧道停用。当前架构及验证见 [直连上游部署](direct-origin-deployment.md)。本文下面保留 9 月 5 日发布时的历史记录。

## 入口与范围

- 平台：灵感平台 > 智能工具箱 > 金融 Skill 评测。
- 地址：<https://finance-eval.demo.linggan.top>，沿用已有入口，不改 EA。
- 用户流程：精选岗位 > 进入评测 > 默认同模型、无 Skill / 有 Skill > 选择任务 > 开始测试 > 实时输出 > 专业对比报告。
- 业务数据全部为固定模拟样本，模型与 MCP 工具实际在线调用。不是生产银行验收，不连接真实 Wind、核保、授信审批或转账执行。

## 这一轮完成

1. 沿用 EA 浅灰侧栏、白色工作区、红色主操作，统一字号、间距、边框、按钮及移动端导航。
2. 方法页采用 React Flow，清楚展示共同试题、A/B 分支、匿名 Judge 和报告；手机端为纵向分支。
3. 保留 React Markdown/GFM 的流式内容渲染与 Recharts 专业评分图表。
4. 修复 MCP 单服务预检被显示成零服务。Runtime 和 MCP 是两个不同组件，不是两个 MCP：一个 OpenJiuwen Runtime 绑定一个只读 MCP，共 16 项工具，按每题要求加载。`read_file` 属于 Runtime 的 Skill 文件读取工具，不计入 MCP 工具数。
5. 6 类岗位提供 13 道开发测试题，另备 6 道留出题。留出题本轮未执行，不宣称留出验证通过。
6. 默认包优先选择已接入的在线样本，不再误选旧 Runtime 专用试题。首页工具需求和题数只计算默认包，不混入历史包。
7. 没有可复算断言的专业量表必须使用模型 Judge，不以“空规则通过”制造满分。

公开模式是受控演示，不是开放的个人 Codex 额度代理：

- 只允许已登录用户运行预制在线包；执行模型从服务端已验证清单选择，Judge 固定。后续模型扩展见 [EA 模型同步记录](ea-model-catalog-2026-09-05.md)。
- 每用户每 UTC 日 3 轮，全站每日 12 轮，最多 3 个未完成任务、单批运行。
- 仅能取消自己发起的任务。共享历史只包含模拟样本。
- 不开放任意 Skill 上传、AI 出题、环境变更及优化发布。完整开发能力仍留在本地实例。
- 身份由平台鉴权结果产生，入口覆盖浏览器同名身份头；内部访问令牌只存在服务端。写请求验证来源。

## 运维与回退

用户级 systemd，已开启 linger，下面四项为持久服务：

```bash
systemctl --user status finance-skill-eval-public
systemctl --user status finance-eval-public-tunnel
systemctl --user status finance-eval-openjiuwen
systemctl --user status finance-eval-reference-mcp
```

配置：`.env.local`、`.runtime.local.json`、`.public-demo/service.env`，均不进入 Git。资产制备脚本 `scripts/prepare-public-demo.mjs`；不要向公开工作区批量复制所有本地上传或运行数据。

网关模板为 `deploy/finance-eval-demo.nginx.template`，发布时替换所有入口令牌占位符，生成文件须为私有权限。Nginx 配置验收后才能 reload。

旧远端容器保留在 `116.204.37.89:56361`，未删除。仅本次演示虚拟主机被切换，其他应用与 EA 不变。网关原配置备份：`/root/nginx-backups/finance-eval-before-curated-20260905.conf`。需要回退时恢复该配置，`nginx -t` 通过后 reload；平台介绍的原数据库行也已单独备份。

此部署适合登录后的受控演示，不宣称高可用生产服务。跨地域隧道、模型网络和个人额度仍是可用性依赖；并发超出当前范围时再考虑独立服务额度与同地域部署。
